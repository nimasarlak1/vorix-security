# راهنمای راه‌اندازی پنل ادمین VORIX SECURITY

## ۱) فایل‌ها را در گیت‌هاب جایگزین/اضافه کنید
همه‌ی فایل‌های این پوشه را با همین مسیر دقیق در ریپوی `nimasarlak1/vorix-security` (شاخه‌ی main) قرار دهید:
- فایل‌های **جدید**: `middleware.ts`، `schema.sql`، همه‌چیز داخل `app/admin/`، `app/api/admin/`، `app/lib/session.ts`، `app/lib/db.ts`
- فایل‌های **جایگزین** (روی نسخه‌ی قبلی بنویسید): `app/api/send-order/route.ts`، `app/robots.ts`، `app/components/Icons.tsx`، `app/components/Contact.tsx`، `app/components/Portfolio.tsx`، `app/data/site.ts`، `app/layout.tsx`، `package.json`

## ۲) دیتابیس D1 را وصل کنید (Binding)
دیتابیس `vorix-db` از قبل در `wrangler.toml` تعریف شده، ولی باید در پنل Cloudflare هم به پروژه‌ی Pages وصل شود:
1. به Cloudflare Dashboard بروید → Workers & Pages → پروژه‌ی `vorix-security`
2. Settings → Functions → D1 database bindings
3. یک Binding جدید بسازید: Variable name = `DB`, D1 database = `vorix-db`
4. Save کنید (نیاز به Deploy مجدد دارد که در مرحله‌ی ۴ انجام می‌شود)

## ۳) دو رمز محرمانه (Secret) بسازید
همان مسیر Settings → Environment variables (یا Secrets):
- `ADMIN_PASSWORD` → یک رمز قوی و جدید برای ورود به پنل ادمین (چیزی که فقط خودتان می‌دانید، هیچ‌جا در کد نیست)
- `SESSION_SECRET` → یک رشته‌ی تصادفی و بلند (مثلاً ۴۰ کاراکتر حروف و عدد قاطی) — فقط برای امضای امن نشست لاگین استفاده می‌شود، لازم نیست به‌خاطر بسپارید

هر دو را به‌صورت **Secret** (نه Variable معمولی) اضافه کنید تا در پنل کلادفلر هم به‌صورت متن ساده دیده نشوند.

⚠️ نکته: `BOT_TOKEN` و `CHAT_ID` که از قبل دارید همان‌جا دست‌نخورده باقی می‌مانند؛ فقط طبق یادداشت قبلی خودتان، توکن ربات تلگرام را هر وقت فرصت شد از BotFather با `/revoke` عوض کنید.

## ۴) Deploy کنید
بعد از ذخیره‌ی binding و secretها، یک Deploy جدید بزنید (کافی است یک commit خالی بزنید یا از پنل Cloudflare گزینه‌ی Retry/Redeploy را بزنید) تا تغییرات فعال شوند.

## ۵) تست کنید
1. به آدرس `https://vorixsecurity.ir/admin` بروید → باید به‌طور خودکار به `/admin/login` هدایت شوید
2. رمزی که در `ADMIN_PASSWORD` گذاشتید را وارد کنید
3. باید وارد پنل شوید و لیست سفارش‌ها (اگر سفارشی ثبت شده باشد) را ببینید
4. یک سفارش آزمایشی از فرم سایت ثبت کنید و ببینید در پنل ادمین ظاهر می‌شود
5. روی نشان وضعیت هر سفارش ضربه بزنید تا وضعیتش عوض شود (جدید ← در حال بررسی ← انجام شد ← لغو شد ← دوباره جدید)

## نکات امنیتی که رعایت شده
- رمز ادمین فقط در Cloudflare Secret است، در هیچ فایلی از کد نیست
- رمز با مقایسه‌ی زمان‌ثابت (timing-safe) بررسی می‌شود تا حدس زدن آن با سنجش زمان پاسخ ممکن نباشد
- کوکی نشست HttpOnly + Secure + SameSite=Strict است (جاوااسکریپت صفحه نمی‌تواند آن را بخواند، فقط روی HTTPS ارسال می‌شود)
- بعد از ۵ تلاش ناموفق ورود از یک IP، به مدت ۱۵ دقیقه قفل می‌شود
- مسیرهای `/admin/*` هم در سطح صفحه (middleware) و هم در سطح API دوباره احراز هویت می‌شوند
- مسیر `/admin` در `robots.ts` از ایندکس گوگل کنار گذاشته شده (disallow + noindex)

## اگر بعداً خواستید
- یک آیکون شناور واتساپ گوشه‌ی صفحه (علاوه بر کارت بخش تماس) اضافه کنم، بگویید تا اضافه کنم.
- برای نمونه‌کارها، به‌محض این‌که عکس واقعی از پروژه‌ها آماده کردید (با رضایت مشتری)، مسیر عکس را در `app/data/portfolio.ts` در فیلد `image` بگذارید و `sample` را `false` کنید.
