# راهنمای پنل مدیریت VORIX SECURITY

- ورود: `/admin` — مدیر کل با نام کاربری `owner` و رمز `ADMIN_PASSWORD` (از Secretهای Cloudflare) وارد می‌شود.
- ادمین‌های دیگر را مدیر کل از تب «ادمین‌ها» می‌سازد و دسترسی هر کدام را (سفارش‌ها، نمونه‌کارها، محصولات، خدمات، مجوزها) تعیین می‌کند. اگر رمز مدیر کل را فراموش کنید، فقط `ADMIN_PASSWORD` را در Cloudflare عوض کنید.
- همه‌ی جدول‌ها خودکار ساخته می‌شوند (پیشوند vx_). نیازی به اجرای SQL دستی نیست.
- نمونه‌کار، آمار، مجوز و محصول هیچ مقدار پیش‌فرضی ندارند؛ تا وارد نکنید نمایش داده نمی‌شوند.
- بله (اختیاری): Secretهای `BALE_BOT_TOKEN` و `BALE_CHAT_ID` را بسازید، بعد در پنل > تنظیمات کلید «بله» را روشن کنید.
- امضا: کد «طراحی شده توسط VORIX.SECURITY» در پنل > تنظیمات و امضا است. سایت‌های دارای کد، در تب نمونه‌کارها «در انتظار تأیید» می‌شوند.
